# Changelog

Rolling bundle — this repository is a patch *overlay* on top of upstream
[southstar21-patches](https://github.com/southstar21dev/southstar21-patches). Each rebuild of the
`bundle-latest` release bumps the build, not the upstream version line.

## [1.4.0](https://github.com/RoToR003/lyrics-blur-spotify/releases/tag/bundle-latest) (2026-11-27)

### ✨ New Features

* **Spotify:** Lyrics blur — blurs the lyrics lines that aren't being sung and keeps the current line sharp (Android 12+), on top of the upstream bundle (upstream base: v1.4.0). Supports Spotify 9.2.4.2644 (APKM).
* Not an official upstream release; **not verified on-device** (see docs/verification.md).
